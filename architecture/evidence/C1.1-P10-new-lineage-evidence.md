**Limitations:** Whole-history checker proves only a given in-memory representation's local consistency. It does **not** prove live authoritative currentness, multi-thread/multi-process serializability, durable storage, authenticated actors, financial provider captures/refunds, event-sourcing, SQL enforcement, real-world restaurant actions or crash recovery. Replaying entire history for each new immutable successor introduces O(n) per operation and potentially O(n²) cumulative cost across long histories; no performance benchmark has been performed.
