## Important qualifications

Atomicity != consistency.
The invariant defines valid result state; atomicity controls whether related changes become visible together.

Atomicity != durability.
The repository remains in memory.

Atomicity != concurrency control.
Concurrent callers can still race across findCurrentById + saveCurrent.

OrderEvolution is a local semantic unit, not a transaction manager.
