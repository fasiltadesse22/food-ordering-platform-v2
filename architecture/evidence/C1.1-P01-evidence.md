## Current evidence


### Spring Boot baseline selection

**Externally verified configuration choice**

The project is pinned to Spring Boot 4.1.1 for this fresh-start baseline. This version choice was checked against the current official Spring Boot documentation; it is not itself evidence that this repository builds in the authoring environment.


### Java runtime

**Observed**

The authoring environment reports Java 21.

### Framework-free core compilation

**Executed and verified**

`./scripts/verify-core.sh` compiles the domain, application services/ports, in-memory adapter, and a deterministic verification harness with `javac --release 21`.

### Framework-free place/get flow

**Executed and verified**

The core verification harness places an order, persists it through the in-memory repository port, reloads it, checks total/status/time, and rejects an empty order.

### Root Maven build

**Not yet verified**

Maven was not installed in the authoring environment, and container network access was unavailable for downloading Maven/Spring dependencies.

Therefore `mvn -B -ntp verify` has **not** executed.

### Spring Boot application startup

**Not yet verified**

Requires the Maven dependency graph to be resolved and the application to run.

### HTTP integration tests

**Not yet verified**

The tests are present but have not been executed in the authoring environment.

### CI

**Structurally demonstrated, not executed**

`.github/workflows/verify.yml` is present and configured to execute the root Maven reactor with Java 21. No CI run result is claimed.

## Checkpoint consequence

This repository is a **C1.1-P01 candidate**, not a frozen verified V8 checkpoint.

It becomes eligible to freeze as `C1.1-P01` only after the root Maven verification and relevant Spring/HTTP tests actually execute successfully.
