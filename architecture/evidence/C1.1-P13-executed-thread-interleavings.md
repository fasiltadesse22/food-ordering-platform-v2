## Reproducibility and causal control

The test creates real JVM `p13-A` and `p13-B` Threads, each with its own OrderWorkflowService. Their `CoordinatedRepository` wraps the **unchanged production** `InMemoryOrderRepository`.

- Each thread captures an actual `findCurrentById` result *before* reaching the `bothRead` CountDownLatch barrier. That forces the shared predecessor without changing the service.
- A controller releases both captured reads; a `firstSaved` latch forces first-writer then second-writer publication.
- Fixed `Clock`, known OrderId, fixed initial history and explicit worker names control confounding variables.
- Traces record thread reads and actual delegated saves.
- Time-bounded awaits and cleanup prevent unbounded stalls.
- Tests assert returned snapshots, final repository Order, occurrence membership and save ordering.
- **The latches are test-only**; the application isn't concurrency-protected.

### Remaining new tests

- Two overlapping cancellations both return accepted while final history contains one occurrence; **not idempotency**.
- Serial preparation→cancellation correctly refuses cancellation.
- Serial cancellation→preparation correctly refuses preparation.
- Independent-OrderId control verifies distinct keys don't overwrite the same map entry in its scenario.
- Separate local-validity test verifies both competing immutable snapshots can pass P10 even when global accepted history loses a fact.
- Trace test verifies named reads, two saves and selected writer ordering.

## Interpretation

**P10 local predicate PASSED** for individual immutable Order snapshots. **Desired cross-request accepted-history preservation FAILED** under these forced interleavings. This is a demonstrated same-key stale-write race, **not** an invalid status/event pair inside the final current Order.

**The CI pipeline passing negative characterization tests is not proof concurrency correctness is implemented.** The tests intentionally assert the existence of the failure; a later fix should change their expected results under the appropriate new consistency protocol.
