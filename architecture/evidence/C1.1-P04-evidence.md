Making typed identifiers and current-state repository authority explicit will let the project distinguish business identity, object identity, snapshots and current state without adding a database or concurrency mechanism.

- OrderRepository renamed around saveCurrent/findCurrentById;
- GetOrderUseCase now accepts typed OrderId;
- HTTP adapter owns String-to-OrderId parsing;
- OrderSnapshot now carries typed OrderId, CustomerId and RestaurantId;
- HTTP response converts typed identities back to transport strings;
- new OrderIdentityAndAuthorityTest covers identity equality, different object instances, stale snapshot and unknown identity;
- P01 framework-free harness was updated mechanically.
