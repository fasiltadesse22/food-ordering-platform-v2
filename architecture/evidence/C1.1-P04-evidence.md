## Evidence classification

- identity equality is value-based;
- Java reference identity is not business identity;
- repository current mapping chooses current in-process state;
- old snapshot can be stale;
- unknown identity produces no current state;
- all inherited behavior remains green.

Structurally demonstrated:
- authority matrix;
- explicit current-state repository contract;
- typed identity preserved until the transport adapter.

Not implemented / not guaranteed:
- database primary-key semantics;
- database uniqueness;
- persistence across restart;
- version/optimistic locking;
- stale-write rejection;
- distributed authority;
- legal lifecycle updates for the synthetic replacement used in the experiment.

## Important qualification

The stale-snapshot experiment uses a synthetic same-identity replacement with different quantity only to create two observable representations.

It does not claim that such a business modification is legal.

Lifecycle legality is intentionally deferred to later parts.

## Preserved fragile state

- in-memory authority disappears on restart;
- saveCurrent can overwrite current same-identity state without version checking;
- no concurrency control;
- no database;
- no cache coherence problem because no cache exists;
- no distributed state owner.
