## Boundaries
- Learning-only action HTTP endpoint currently **has no caller authentication/authorization**; not production safe for public customer/restaurant actions.
- No retry/circuit breaker, durable database, provider payment/refund, Kafka, Saga, autoscaling, distributed tracing, actual production SLI measurement, crash recovery or concurrent atomicity.
- Tests use injected technical exceptions, not an actual persistent repository outage or network crash.
- Current repository is process-local memory; current Order state can be lost on restart or overwritten by racing readers.
- HTTP 409 may be contract-correct but should still be measured as customer/product friction if frequent.
- HTTP 500 from a future durable/remote operation cannot alone prove whether the effect committed.
