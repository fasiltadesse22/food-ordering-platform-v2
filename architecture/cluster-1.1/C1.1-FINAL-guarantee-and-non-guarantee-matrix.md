# C1.1-FINAL — Guarantee / Non-Guarantee Matrix

## Scoped guarantees supported by current implementation + evidence

| Property | Current scoped claim |
|---|---|
| Place Order baseline | selected valid command creates an in-process PLACED Order through the real application path |
| Lifecycle legality | current domain transition mechanism rejects selected illegal source-state transitions |
| Actor ownership guards | selected Customer/Restaurant operations reject mismatched typed business actor IDs |
| Lifecycle/history coherence | normal Order construction checks current selected lifecycle/history invariants |
| Completion local atomicity | normal completion constructs status+history together inside one immutable successor |
| Refund duplicate suppression | once REFUND_REQUESTED is present, another selected request is rejected |
| Business/technical taxonomy | selected known domain failures are translated to OrderActionResult.Rejected; unexpected repository runtime failures are not broadly converted into business rejections |
| Current in-process authority | InMemoryOrderRepository current mapping is authoritative for Order state inside the running process |
| Evidence reproducibility | current CI runs the Maven reactor and P18 real process restart experiment |

Every guarantee above is intentionally scoped.

## Evidence-strength language

Use:
- requirement — normative target;
- implementation/structural fact — source/config exists;
- observation — executed result;
- evidence-backed inference — mechanism conclusion supported by observation + structure;
- scoped guarantee — claim justified for stated boundary;
- assumption/hypothesis — not yet established;
- non-guarantee — explicitly outside current evidence/implementation.

## Forbidden broad claims at C1.1-FINAL

Do not say:
- "the repository is thread safe, so Order updates are safe";
- "the application is transactional";
- "payment is idempotent";
- "exactly once";
- "Orders are persisted";
- "the system is highly available";
- "the system is production durable";
- "ActorContext authenticates users";
- "a passing test proves all interleavings are safe".
