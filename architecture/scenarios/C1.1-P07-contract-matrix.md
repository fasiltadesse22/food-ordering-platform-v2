# C1.1-P07 — Guard / Precondition / Postcondition Matrix

| Operation | State precondition | Contextual guard | Successful postcondition |
|---|---|---|---|
| Accept | PLACED | acting restaurant == Order.restaurantId | status ACCEPTED; RESTAURANT_ACCEPTED appended |
| Reject | PLACED | acting restaurant == Order.restaurantId | status REJECTED; RESTAURANT_REJECTED appended |
| Cancel | PLACED | acting customer == Order.customerId | status CANCELLED; ORDER_CANCELLED appended |
| Start Preparation | ACCEPTED | acting restaurant == Order.restaurantId | status PREPARING; PREPARATION_STARTED appended |
| Complete | PREPARING | acting restaurant == Order.restaurantId | status COMPLETED; ORDER_COMPLETED appended |
| Refund Request | REJECTED or CANCELLED | PAYMENT_RECORDED exists | lifecycle unchanged; REFUND_REQUESTED appended |
| Record Payment | none added in P07 | none added in P07 | lifecycle unchanged; PAYMENT_RECORDED appended |

## Stable postconditions for lifecycle evolution

Successful lifecycle transitions preserve:
- OrderId;
- CustomerId;
- RestaurantId;
- order lines;
- placedAt;
- derived total.

## Failure postcondition

If state precondition or contextual guard fails:
- no new current Order is saved;
- attempted workflow occurrence is not appended;
- previous current Order remains authoritative.

## Scope qualification

The matrix is the current P07 contract.

It is not a complete authorization, payment or concurrency policy.
