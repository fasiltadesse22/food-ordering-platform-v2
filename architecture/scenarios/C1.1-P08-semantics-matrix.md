# C1.1-P08 — Lifecycle / Effect Semantics Matrix

| State / occurrence | Current semantic classification | Important consequence |
|---|---|---|
| PLACED | nonterminal | may accept/reject/cancel; may currently modify |
| ACCEPTED | nonterminal | may start preparation |
| PREPARING | nonterminal lifecycle, irreversible physical pressure | may complete; "unprepare" is not modeled |
| REJECTED | terminal lifecycle | no further lifecycle transition; paid rejection may request refund |
| CANCELLED | terminal lifecycle | no further lifecycle transition; paid cancellation may request refund |
| COMPLETED | terminal lifecycle | cannot cancel or modify in current model |
| PAYMENT_RECORDED | historical/compensable effect | remains in history after refund request |
| REFUND_REQUESTED | compensating action request | does not erase payment or change terminal lifecycle state |
| ORDER_MODIFIED | non-lifecycle workflow occurrence | permitted only while PLACED |

## Exact rollback is not modeled

There is no transition such as:

CANCELLED → PLACED
COMPLETED → PREPARING
REFUND_REQUESTED → remove PAYMENT_RECORDED

Those would pretend history can be rewritten.

## Scope boundary

P08 models compensation semantics locally.

It does not implement:
- Saga;
- distributed rollback;
- external payment/refund provider;
- refund completion;
- human compensation for irreversible preparation;
- idempotent retry.
