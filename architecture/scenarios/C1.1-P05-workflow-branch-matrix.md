# C1.1-P05 — Workflow Branch Matrix

| Scenario | Selected sequence after placement | Main handoff / consequence | P05 interpretation |
|---|---|---|---|
| Happy path | Payment recorded → Restaurant accepted → Preparation started → Completed | Payment participant → Restaurant | Executable selected path |
| Restaurant rejection after payment | Payment recorded → Restaurant rejected → Refund requested | Restaurant → Platform/refund concern | Executable alternative |
| Cancellation before payment | Cancelled | Customer decision; no payment milestone in trace | Executable alternative |
| Cancellation after payment | Payment recorded → Cancelled → Refund requested | Customer → Platform/refund concern | Executable conditional branch |
| Suspicious/out-of-order | Preparation started → Accepted → Rejected → Completed | Contradictory lifecycle meaning | Executable fragility, not valid business path |

## Reading rule

The matrix is a workflow-discovery artifact.

It does not define a transition table.

"Executable" means the P05 implementation can record the sequence and tests reproduce it.

It does not mean every executable sequence is business-valid.

That distinction is the primary evidence handed to P06.
