# C1.1-P09 — HTTP Mapping

## Important rule

HTTP mapping is an adapter decision over application semantics.

Do not define business failure as "anything with a 4xx".

## Current mappings

| Application outcome | HTTP status | Meaning |
|---|---:|---|
| Accepted cancellation | 200 | business operation succeeded |
| ORDER_NOT_FOUND | 404 | expected requested resource absence |
| ownership rejection | 403 | actor context does not satisfy business ownership |
| ILLEGAL_TRANSITION | 409 | requested operation conflicts with current lifecycle |
| refund/modification conflict codes | 409 | known business rule conflict |
| malformed value/request | 400 | structural request/input problem |
| unexpected runtime/technical exception | 500 | server could not execute correctly |

## Security qualification

403 mapping demonstrates business ownership semantics only.

P09 still does not prove caller identity is authenticated.

## Information disclosure

Unexpected technical failure returns a generic 500 detail rather than exposing internal exception text.

Detailed diagnostics should belong in internal logs/traces later, not the public response.
