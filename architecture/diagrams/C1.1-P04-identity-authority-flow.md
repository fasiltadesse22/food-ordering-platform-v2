# C1.1-P04 — Identity and Authority Flow

HTTP order-id string
  ↓ parse
OrderId
  ↓ lookup
OrderRepository
  ↓ current state
Order
  ├→ OrderSnapshot
  │    ↓
  │  OrderResponse
  │
  └→ domain facts may reference same OrderId

Interpretation:

- OrderId preserves identity across representation boundaries.
- Repository lookup chooses current in-process Order state.
- Snapshot and HTTP response are derived observations.
- A fact can refer to the same identity without being the current state store.
