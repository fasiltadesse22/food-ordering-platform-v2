# C1.1-P05 — Workflow Sequences

## Selected happy path

Customer
  → Place Order
Platform
  → current Order / OrderPlaced
Payment Participant
  → Payment Recorded
Restaurant Operator
  → Accept Order
Restaurant Operator
  → Start Preparation
Restaurant Operator
  → Complete Order

## Rejection after recorded payment

Customer
  → Place Order
Payment Participant
  → Payment Recorded
Restaurant Operator
  → Reject Order
Platform
  → Refund Requested

## Cancellation after recorded payment

Customer
  → Place Order
Payment Participant
  → Payment Recorded
Customer
  → Cancel Order
Platform
  → Refund Requested

## Important interpretation

These arrows show business workflow order and handoff.

They do not show:
- microservices;
- HTTP calls between participants;
- Kafka topics;
- Saga steps;
- database ownership;
- final lifecycle-state transitions.
