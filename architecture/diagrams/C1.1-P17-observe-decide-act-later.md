# C1.1-P17 — Observe → Decide → Authority Changes → Act Later

## Generic temporal gap

```text
Actor / Worker             Local Snapshot             Authority
     |                           |                        |
     |------ read -------------> |                        |
     |<----- S0 -----------------|<-----------------------|
     |                           |                        |
     | decide using S0           |                        |
     |                           |                        |
     |                           |      other change ---->|
     |                           |                        | S1
     |                           |                        |
     | apply decision(S0) ------------------------------>|
     |                           |                        |
     |                           |              stale overwrite/effect
```

## Payment-after-cancellation example

```text
Payment worker             Stale copy                 Order Authority
     |                         |                           |
     |<----- PLACED -----------|<--------------------------|
     | decide "payable"        |                           |
     |                         |                           |
Customer cancellation ----------------------------------->|
     |                         |                           | CANCELLED
     |                         |                           |
     | record payment on       |                           |
     | old PLACED copy         |                           |
     |------------------------ save stale PLACED+PAYMENT ->|
     |                         |                           | PLACED+PAYMENT
```

The cancellation existed and was authoritative before the stale save.

The stale save does not merely add a payment fact.
It can overwrite the newer lifecycle/history because no version conflict is detected.
