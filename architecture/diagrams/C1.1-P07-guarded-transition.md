# C1.1-P07 — Guarded Transition

Requested lifecycle operation
        ↓
Load current Order by OrderId
        ↓
State precondition
Does current status match transition source?
        ├── no → IllegalOrderTransitionException
        │
        └── yes
              ↓
        Contextual guard
        Does business context match?
              ├── no → OrderGuardViolationException
              │
              └── yes
                    ↓
              Evolve immutable Order
                    ↓
              Verify through contract tests:
              - target state
              - identity preserved
              - stable data preserved
              - occurrence appended
                    ↓
              saveCurrent(next Order)

Refund request uses a non-transition guard path:

REJECTED/CANCELLED?
    ↓ yes
PAYMENT_RECORDED exists?
    ↓ yes
append REFUND_REQUESTED
without changing OrderStatus
