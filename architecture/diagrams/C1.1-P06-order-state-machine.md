# C1.1-P06 — Order Lifecycle

PLACED
  ├── accept ──────────────→ ACCEPTED
  │                           │
  │                           └── start preparation ─→ PREPARING
  │                                                     │
  │                                                     └── complete ─→ COMPLETED
  │
  ├── reject ──────────────→ REJECTED
  │
  └── cancel ──────────────→ CANCELLED

Orthogonal workflow milestones:

PAYMENT_RECORDED
REFUND_REQUESTED

These do not alter OrderStatus in P06.

## Why orthogonal matters

A paid order can still be:
- PLACED before the restaurant decision;
- REJECTED and awaiting refund-related work;
- CANCELLED and awaiting refund-related work.

Representing payment as OrderStatus would lose that simultaneous information.
