# C1.1-P03 — Semantic Flow

Customer Goal
  ↓
Place-order Intent
  ↓
HTTP PlaceOrderRequest
  ↓
PlaceOrderCommand
  ↓
Application Decision
  ├── reject → PlaceOrderResult.Rejected
  └── accept → Order state → in-memory save → OrderPlaced domain fact → PlaceOrderResult.Accepted

## Boundary interpretation

- Goal and intent are business semantics.
- PlaceOrderRequest is HTTP transport representation.
- PlaceOrderCommand is an application instruction.
- The application makes a decision.
- A rejected command does not create the accepted fact.
- OrderPlaced is a local domain fact, not a message.
- No network boundary exists after the HTTP adapter in the current topology.
