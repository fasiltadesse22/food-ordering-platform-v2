# C1.1-P13 — Deterministic Conflict Interleaving

## Sequential control

```text
Authority      Accept caller        Reject caller
   |                |                    |
PLACED              |                    |
   |<--- read -------|                    |
   |                | validate ACCEPT    |
   |<-- ACCEPTED ----|                    |
ACCEPTED            |                    |
   |<-------------------- read -----------|
   |                                     | validate REJECT
   |                                     | sees ACCEPTED
   |                                     | REJECTED:
   |                                     | ILLEGAL_TRANSITION
```

## Concurrent interleaving — ACCEPT saves first

```text
Authority        Accept A                 Reject B
   |                |                        |
PLACED              |                        |
   |<--- read -------|                        |
   |<------------------------ read -----------|
   |                | both hold PLACED        |
   |                |                        |
   |                | derive ACCEPTED        | derive REJECTED
   |                |                        |
   |<-- save A ------|                        |
ACCEPTED            | returns Accepted       |
   |                                         |
   |<--------------------------- save B ------|
REJECTED                                      | returns Accepted
```

Final authority contains only the successor derived by B from the original PLACED snapshot.

## Reverse save order

If B saves before A, both still report Accepted but final authority becomes ACCEPTED.

Only the scheduling order changed.

That schedule sensitivity is direct evidence of a concurrency conflict.
