```text
Caller              Application            Payment Authority        Order Authority
  |                      |                        |                       |
  | PAY ---------------->|                        |                       |
  |                      |---- charge ---------->|                       |
  |                      |                        | commit charge #1      |
  |                      |                        |                       |
  |                      |< - X response lost ---|                       |
  |                      |                                                |
  |<----- failure -------|                                                |
  |                                                                       |
  | PAY retry ---------->|                                                |
  |                      |---- charge ---------->|                       |
  |                      |                        | commit charge #2      |
  |                      |<--- success ----------|                       |
  |                      |---------------------------- record payment --->|
  |                      |                                                | PAYMENT_RECORDED
  |<---- success --------|                                                |
```

Final modeled truths:

Payment Authority:
2 charges.

Order Authority:
1 PAYMENT_RECORDED.

The first charge cannot be inferred away because the local record is missing.

## Knowledge after first lost response

Payment Authority:
knows the charge committed.

Application:
knows only that a success response was not received.

Caller:
sees failure/timeout.

Order Authority:
contains no payment fact.

This is an unknown-outcome problem, not proof that payment failed.
